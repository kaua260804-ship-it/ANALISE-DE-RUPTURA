# Sistema de Análise de Dados Fribal

Sistema web para análise de dados de estoque, vendas e cadastro de produtos.

## 📁 Estrutura de Arquivos

## 📊 Arquivos Necessários

Coloque os seguintes arquivos Excel na pasta raiz:

1. **BASE ESTOQUE.xlsx** - Com as abas:
   - `ESTOQUE DA LOJAS` (ou `ESTOQUE LOJA`)
   - `ESTOQUE CDBR`

2. **VENDA 26.xlsx** - Com a aba `VENDA`

3. **BASE CADASTRO.xlsx** - Com a aba `ARVORE`

## 🚀 Como Usar

1. Abra o arquivo `index.html` em um servidor web
   - Recomendado: Use o Live Server do VS Code
   - Ou hospede no GitHub Pages

2. O sistema carregará automaticamente os dados

3. Use os filtros para analisar os dados

4. Exporte os dados filtrados em CSV ou Excel

## 🔧 Funcionalidades

- ✅ Visualização em tabela
- ✅ Filtros dinâmicos
- ✅ Ordenação por colunas
- ✅ Paginação (50 registros/página)
- ✅ Exportação CSV e Excel
- ✅ Busca global
- ✅ Dashboard com cards
- ✅ Gráficos interativos
- ✅ Design responsivo

## 📱 Tecnologias

- HTML5
- CSS3 (Grid/Flexbox)
- JavaScript (Vanilla)
- SheetJS (para leitura de Excel)

## 🌐 Deploy no GitHub Pages

1. Crie um repositório no GitHub
2. Faça upload dos arquivos
3. Vá em Settings > Pages
4. Selecione a branch main
5. Acesse: `https://seu-usuario.github.io/nome-repositorio/`
